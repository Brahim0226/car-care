# صيانة سيارتي

تطبيق أندرويد لمتابعة صيانة السيارة: زيت المحرك، فلتر الزيت، فلتر الهواء، فلتر الوقود، فلتر المكيّف، سير/سلسلة التوزيع، العجلات، الفرامل، شمعات الإشعال، البطارية، مع إمكانية إضافة بنود أخرى.

## المميزات
- تسجيل اسم السيارة والعداد الحالي
- لكل بند: فاصل بالكيلومتر و/أو بالأشهر (قابل للتعديل)
- حالة كل بند: عادي (أخضر) / قريب (برتقالي) / متأخر (أحمر)، والبنود المتأخرة تظهر في الأعلى
- تسجيل كل صيانة: التاريخ، العداد، السعر، ملاحظة
- سجل كامل ومجموع المصاريف بالدينار
- البيانات محفوظة في الهاتف ويخدم بدون إنترنت

> الفواصل الافتراضية تقريبية. اعتمد دائماً على دليل صيانة سيارتك وعدّلها من داخل التطبيق.

## كيف تطلع ملف APK
1. ارفع كل ملفات المشروع إلى مستودع GitHub (الفرع `main`).
2. افتح تبويب **Actions** ثم **Build APK**، واضغط **Run workflow** (ولا ينطلق تلقائياً عند كل push).
3. بعد ما يخلص (حوالي 5 إلى 10 دقائق)، ادخل على التشغيل الناجح ونزّل **car-maintenance-apk** من قسم Artifacts.
4. فك الضغط، وانقل `app-release.apk` للهاتف وثبّته (فعّل "تثبيت من مصادر غير معروفة" إذا طلب).

## تشغيل محلي (اختياري)
```
flutter create --platforms=android .
flutter pub get
flutter run
```

## التنبيهات
- **بالتاريخ:** إشعار قبل الموعد بأسبوع وفي يوم الموعد (الساعة 9 صباحاً)، حتى لو التطبيق مغلق.
- **بالكيلومتر:** إشعار عند فتح التطبيق أو تحديث العداد إذا اقترب البند أو تجاوز موعده.
- زر الجرس في أعلى التطبيق يرسل إشعاراً تجريبياً للتأكد أن كل شيء يعمل.
- التوقيت المعتمد: الجزائر (Africa/Algiers).

## الإصدار 1.1
- **عدة سيارات:** كل سيارة لها بنودها وسجلها وعدادها (زر ⇄ في بطاقة السيارة).
- **ثمن الشراء (اختياري):** يدخل في المجموع الكلي مع الصيانة.
- **تقارير PDF:** من زر PDF في أعلى التطبيق؛ تختار السيارات، وهل يظهر ثمن الشراء و/أو الصيانة (وأي بنود)، والمجموع يُحسب على ما اخترته فقط.
- **نسخ احتياطي:** من القائمة ⋮ (نسخ البيانات ثم استعادتها لاحقاً).
- **تحديث بدون حذف:** البناء يُوقَّع بمفتاح ثابت يُقرأ من GitHub Secrets، فتُثبَّت النسخ الجديدة فوق القديمة وتبقى البيانات.

> ملاحظة أمان: مفتاح التوقيع **ليس** في المستودع. يُحفظ في GitHub Secrets (`KEYSTORE_BASE64` و`KEYSTORE_PASSWORD` و`KEY_ALIAS`)، ويجب الاحتفاظ بنسخة من ملف `.jks` وكلمة سره: بدونهما لا يمكن إصدار تحديثات تُثبَّت فوق القديمة.

## اللغات / Langues
- التطبيق بالعربية والفرنسية. من القائمة ⋮ ← «اللغة / Langue». اللغة الافتراضية هي لغة الهاتف (فرنسية إن كان الهاتف بالفرنسية، وإلا العربية).
- الواجهة والتقارير PDF والإشعارات تتبع اللغة المختارة. البنود الافتراضية تُترجم تلقائياً، أما البنود التي أضفتها أو غيّرت اسمها فتبقى بالاسم الذي كتبته.
